# Platform Engineering

Platform Engineering es la disciplina que construye y mantiene las herramientas, la infraestructura y los flujos de trabajo que permiten a los equipos de desarrollo entregar software de forma rápida, segura y repetible.

## ¿Qué cubre este portal?

Este portal documenta las prácticas y herramientas de plataforma adoptadas en el proyecto, organizadas en cuatro áreas:

| Área | Descripción |
|---|---|
| **CI/CD** | Pipelines de integración y entrega continua con GitHub Actions |
| **Containers** | Empaquetado y ejecución de aplicaciones con Docker |
| **IaC** | Infraestructura como código con Terraform y GCP |
| **Observability** | Logging estructurado, métricas y alertas |

## Relación con arquitectura de software

Las prácticas de plataforma aquí documentadas soportan la arquitectura de microservicios descrita en el portal de [Software Architecture Docs](http://8.233.204.126/thesis-doc-test-2/). Los pipelines CI/CD están diseñados para desplegar servicios independientes con ciclos de vida desacoplados.

## Principios guía

- **Automatización sobre proceso manual**: todo lo que se ejecuta más de una vez debe estar en un pipeline.
- **Infraestructura declarativa**: el estado deseado del sistema vive en código, no en wikis.
- **Observabilidad desde el diseño**: los servicios deben emitir logs, métricas y trazas desde el primer deploy.
- **Seguridad por defecto**: secretos en Secret Manager, credenciales vía OIDC, mínimo privilegio en IAM.
